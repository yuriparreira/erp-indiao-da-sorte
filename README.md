# Indião da Sorte · Rifas (telas)

Telas do app de gestão das rifas da Indião da Sorte, publicadas pelo GitHub Pages em **erp.indiaodasorte.com**.

Este repositório tem só as telas, geradas a partir do código do app. Não tem dados, planilhas, senhas nem chaves: tudo
isso fica no servidor do app (Google Apps Script), que confere o e-mail e a senha de cada pessoa a cada pedido.

- `index.html`: as telas da versão atual.
- `v/<versão>/`: as telas de cada versão. Quando o servidor está numa versão diferente, a página passa para a pasta dela.
- Os arquivos são gerados pelo `empacotar.js` do app (pasta `dist/site`). Não edite à mão: gere de novo.
